# SnapNote cho Windows

Phần mềm chụp màn hình, chú thích (hình, mũi tên, chữ, callout) và ghi âm cuộc gọi cho Windows.

Repo này chỉ chứa bản cài đặt. Tải file `SnapNote-Setup-x.y.z.exe` mới nhất ở mục [Releases](https://github.com/antS2nat/SnapNote_Win/releases/latest).

Ứng dụng tự kiểm tra và cập nhật từ trang Releases này (Cài đặt → Cập nhật).
